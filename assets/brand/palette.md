# Ultimate PC Manager · C2 Bridge

Phosphor green, near-black surfaces with a green tint, and monospaced characters in the banner. The C2 symbol combines a U with a central module. The icon plate fills 88% of the square canvas.

| Role | Dark theme | Light theme |
| --- | --- | --- |
| Accent, buttons, and selection | `#52FF8C` | `#08713A` |
| Text on a solid accent background | `#07120C` | `#F1FAF3` |
| Background | `#07120C` | `#F1FAF3` |
| Secondary surface | `#102519` | `#DEEFE3` |
| Primary text | `#E1F7E7` | `#122D1D` |
| Secondary text | `#86A893` | `#426A50` |

The wordmark uses Space Grotesk at weight 700 for “Ultimate” and 500 for “PC Manager.” The variable font is included under the SIL Open Font License 1.1. The PNG wordmarks are ready to use without installing the font. [Font source](https://github.com/google/fonts/tree/main/ofl/spacegrotesk)

| File | Use |
| --- | --- |
| `icon.ico` | Windows icon with 16, 20, 24, 32, 40, 48, 64, 128, and 256 px frames |
| `icon-1024.png` / `icon.svg` | Main icon with transparency outside the plate |
| `icon-small.png` / `icon-small.svg` | Small icon variant with flat colors and a stronger outline |
| `mark.png` / `mark.svg` | Standalone symbol without the plate. The PNG is 512 × 512 px |
| `mark-light.png` / `mark-light.svg` | Dark green symbol for the light sidebar |
| `logo-dark.png`, `logo-light.png` | Transparent horizontal wordmarks, 1200 × 300 px. The suffix indicates the intended theme |
| `banner.png` | GitHub and release banner, 1280 × 640 px |
| `preview.png` | A comparison on light and dark backgrounds using the actual 16 and 32 px ICO frames |

The ZIP places the files under `assets/brand/`. ICO frames from 16 to 40 px use the compact variant.
